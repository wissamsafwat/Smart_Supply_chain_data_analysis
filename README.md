# Supply Chain Analysis Dashboard

**Group Code:** `YAT792A_CAI5_DAT1_S2` | **Team 3**

An interactive Power BI dashboard analyzing supply chain operations across customers, orders, products, and shipments.

## Overview
This project transforms raw supply chain data into a structured data model and an interactive multi-page dashboard to track operational performance, order trends, product metrics, and shipping efficiency. Throughout development, this repository served as our central workspace for sharing datasets, SQL scripts, and individual Power BI dashboard files across the team before consolidating everything into the final deliverable.

## Tools & Technologies
* **Excel & Power Query:** Data cleaning, transformation, and preparation
* **SQL Server:** Database integration, querying, and structured data modeling
* **Power BI:** Data visualization, DAX measures, and interactive dashboard reporting

## Data Dimensions
The data model is structured around six core dimensions:
* **Customer:** Customer demographics and purchasing behavior
* **Date:** Time-based trends and seasonality
* **Department:** Departmental performance breakdowns
* **Location:** Geographic and regional comparisons
* **Product:** Product-level sales and category performance
* **Shipment:** Delivery status, shipping modes, and fulfillment tracking

## Dashboard Pages
1. **Executive Summary:** High-level KPIs, overall sales, profit, and top-level business insights.
2. **Customers:** Customer segmentation, geographic distribution, and top buyers.
3. **Orders:** Order volume, status breakdowns, and sales trends over time.
4. **Products:** Category and product-level revenue, profit margins, and top performers.
5. **Shipments:** Delivery timelines, shipping modes, and on-time delivery performance.
